# Project Instructions

## Stack
- Next.js + React + TypeScript
- Tailwind CSS
- LiveKit/WebRTC
- Node.js
- PostgreSQL + Prisma
- Docker Compose

## Development Rules
- Use TypeScript strictly.
- Keep the architecture modular and scalable.
- Prefer reusable React components.
- Do not add unnecessary dependencies.
- Use environment variables for secrets and service configuration.
- Never hardcode LiveKit credentials.
- Keep WebRTC/LiveKit logic isolated from UI components.
- Follow clean and consistent naming conventions.
- Implement and test the MVP before adding extra features.

## UI
- Modern, minimal and responsive.
- Dark mode as the default.
- Clean SaaS-style interface.
- Prioritize the shared screen.
- Use subtle animations and rounded components.
